# Seamstress
🧵 A safe tag-length-value byte stream handler for SMF, RIFF, IFF and more. The reference JS implementation of SEAM (Simple Extensible Arbitrary Messaging).

Documentation available on [JSR](https://jsr.io/@ltgc/seamstress).

Like the project and want to support it? Learn how in the parent project Octavia ([Codeberg](https://codeberg.org/ltgc/octavia/), [GitHub](https://github.com/ltgcgo/octavia/))!
